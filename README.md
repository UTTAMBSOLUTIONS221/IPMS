
This project is a simple Insurance Policy Management System built using Angular for the front-end and C# (.NET) for the back-end API. It demonstrates basic CRUD operations, JWT-based authentication, error handling, and database interaction with Entity Framework Core.
Features
1. Back-end (C# .NET API)
JWT Authentication: Secure endpoints with JSON Web Tokens.
CRUD Operations: Create, Read, Update, and Delete insurance policies and policy holders.
Error Handling: Centralized error handling for consistent responses.
Database Integration: Uses Entity Framework Core with SQL Server for persistence.
RESTful API: Exposes endpoints for managing insurance policies and policy holders.
2. Front-end (Angular)
Dashboard: View a list of all insurance policies.
Forms: Add and edit policies and policy holders.
Search and Filter: Filter policies based on search criteria.
User-Friendly Interface: Responsive and intuitive UI.
Prerequisites
Back-end

.NET 6 SDK or later
SQL Server (local or cloud)
Postman (for testing APIs)
Front-end

Node.js and npm
Angular CLI
